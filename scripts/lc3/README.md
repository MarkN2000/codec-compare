# LC3接続コード

`liblc3enc.c`、`liblc3dec.c`、`lc3.c`はFFmpeg公式のコミット
`a3c5339578cb1d54322e06b6bd1c8852fc6abc29`から取得した未変更のソースです。
著作権・ライセンス表示は各ファイルに保持しています。

`backport.py`でFFmpeg 5.1.4の構造体・フレームAPIと登録処理へ合わせます。
エンコーダーの最終フレームは常に遅延分を排出し、元のサンプル数はサイト側でLC3ヘッダーへ記録します。
コア更新時は移植を除去できるか確認し、同じ位置合わせ・末尾の検証を実行してください。

Google liblc3はコミット`f9c127fd35975a0494b9e187589501ee984dc4b6`に固定します。
高解像度モードやLC3plusをサイトの設定として公開せず、Bluetooth LE AudioのLC3を扱います。
